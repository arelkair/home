# Home
The portfolio of Arel Kair: [arelkair.dev](https://arelkair.dev).
## Features
- A home page listing Wii Party Recomp, Nivra and Pool, each linking to its repository
- A single column of text in black and white, set in Allo
- Built with Astro and Tailwind CSS, with no JavaScript sent to the browser
## Development
```
npm install
npm run dev      http://localhost:4321
npm run build    type check and build into dist/
```
