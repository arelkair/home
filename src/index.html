About

I build with AI: agents, automations, web projects and games.

My first web page went online in May 2026. Since then I have published two multiplayer browser games, both of which connect players directly through PeerJS instead of a game server, and Nivra, an organizer that keeps its data on your own device.

The games run in the browser and are free to open. They, this site and Wii Party Recomp are open source on GitHub.

Since September 2026 I have also been working on Wii Party Recomp, which translates a Wii game into C++ so it runs natively on PC.
